# Templates

Templates prontos para copiar nos seus projetos. Eles são o "harness mínimo" —
o ponto de partida antes de evoluir para um harness completo.

| Arquivo | Papel |
|---------|-------|
| `AGENTS.md` | O roteiro do agente: o que ler, como verificar, quando terminar. |
| `feature_list.json` | Fonte de verdade do que fazer, com status por feature. |
| `claude-progress.md` | Progresso da sessão atual. |
| `session-handoff.md` | Estado deixado pela sessão anterior. |
| `policies/scope-control.md` | Escopo declarado antes de editar. |
| `policies/definition-of-done.md` | O que prova que uma feature está pronta. |
